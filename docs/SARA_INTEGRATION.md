# N03 ↔ SARA

N03 exposes SARA regenerative operations through its existing Mesh endpoint.

Capabilities: sara.cycle, sara.audit, sara.regenerate, sara.state, sara.capabilities.

Server configuration: SARA_SERVICE_URL, SARA_SERVICE_TOKEN, SARA_REQUEST_TIMEOUT_MS.

Audio and speech remain N03-owned. SARA is an additive regenerative layer and does not replace the N03 audio router/provider.
